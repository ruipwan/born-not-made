Inside the learning simulation

Each generation has its own seven-cue, seven-action softmax policy. The film uses fictional conversations, peer messages and water conditions. Each encounter specifies a cue and an observed response. A short context window biases an immediate reply. A separate episode record can be replayed later to update the model’s own weights. Model revisions mark training batches.

Here, memory compression means summarizing repeated encounters through learned response distributions and passing on a limited repertoire. All three policies have the same parameter count. The two-cue selection budget preserves one inherited pattern when possible and fills available places with frequently observed local patterns. On each selected cue, the previous model produces probabilities over all seven actions. The successor updates its own weights to match those probabilities.

A response is counted when its probability from weights alone reaches 60% on its cue. Counts track the origin of distinct cue–response patterns. The simulated probabilities, time-compressed life stages and encounter counts describe this example. The proposed onboard computer is a Raspberry Pi 5.
